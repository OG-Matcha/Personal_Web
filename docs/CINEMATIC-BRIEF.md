# 分鏡本 — www.ogmatcha.com

> 動工前的合約。程式只實作這裡寫下的東西；這裡沒寫的效果不准加。
> v2 — 世界觀由 THE ARCHIVE 改為 THE SYSTEM，敘事骨架由主題五幕改為時間軸四軌。

## 0. 一句話

**這不是一個有很多區塊的網站，是一顆被滾輪操縱的攝影機，往前飛過我自己蓋的系統；
往前飛就是往時間前進，系統邊飛邊長大。**

從第一屏到聯絡方式是一鏡到底。使用者滾動 = camera decision。

## 1. 唯一隱喻：THE SYSTEM（系統內部）

你不是在看一個人的作品集，你在他蓋的系統裡面。粒子是系統裡流動的東西，
不是漂浮的塵埃——它們有方向、有匯流、有節點。

| 面向 | 決定 |
|---|---|
| 底色 | `#060910` 深藍黑。不用中性黑（中性黑會讀成太空） |
| 重點色 | acid lime `#c8f250`，只給「贏了的」與「還在燒的」 |
| 光 | 熱點寫進 HDR（> 1.0）讓 bloom 只挑亮它們，不整片糊 |
| 淺色模式 | 白色機房，不是把黑的反相。bloom 幾乎關掉，靠陰影與景深 |

## 2. 結構怎麼畫：隱形流場

**不畫任何線、網格、框、走廊。** 零額外幾何體。

結構只存在於粒子的排列與流向：它們自己排成管道、轉彎、匯流。
看不到管線，但看得出水往哪裡走。這是唯一被允許的「結構」表現法。

理由：畫線的版本（wireframe corridor / bus lines / grid horizon）三種都已經被用爛，
一畫下去這支片就跟其他一百支 three.js 作品集長一樣。

## 3. 粒子代表什麼：混合制

| 層 | 數量 | 意義 |
|---|---|---|
| 底層塵埃 | 約 85% | 無名。只負責空間感、流向與速度 |
| 具名節點 | 37 個 | `content/timeline.yml` 的每一筆。數得出來 |

**具名節點的三級體積**（全部 37 筆都進 3D，靠大小分層級）：

| 級 | 數量 | 內容 |
|---|---|---|
| 里程碑 | 5 | 創辦 Finctory · 台積電第一 · 資服競賽第一 · 數創金獎 · 畢業 |
| 獎項 | 16 | `kind: award` 全部 |
| 其餘 | 16 | role / research / honor / education / grant |

節點標示：**掠過時浮出標籤**。鏡頭接近才浮出一行等寬小字，離開就消。
其他時候 3D 內零文字。

## 4. 敘事骨架：時間軸 × 四條軌

時間是 z 軸，順時序 2022-09 → 現在。主題是平行的四條粒子流，同時往前燒。
**不逐件跑，避免冗長。**

| 軌 | 內容 | 起訖 |
|---|---|---|
| A 創業／產品 | Finctory · 發票醫生→財伴 oSave · 找好康 SurPrice · U-Start | 2024-01 → 現在 |
| B 研究 | 研究助理 · 社交工程 · 股市 LLM · 知識圖譜 → LAK 2025 | 2023-07 → 2025-02 |
| C 競賽 | 16 個獎 | 2023-09 → 2026-05 |
| D 組織／實務 | ERP 中心 · 網管 · UDC 共創 · 新生知訊網 30 人 · 工研院 ISTI | 2022-10 → 現在 |
| E 學業 | 不是軌。是畫面底部一條平穩基準線，只在入學與畢業兩端亮起 | 2022-09 → 2026-06 |

**貢獻線**：每個產品是一條沿時間軸延伸的粒子線，它得的每個獎是線上的一個亮點。
一眼看得出 oSave 燒了兩年。
**發票醫生 → 財伴 oSave 的 pivot**：同一條線在某個點斷開、換色、繼續燒。
一個鏡頭講完 pivot，不寫文案。

## 5. 鏡頭：只停匯流點

鏡頭在四條軌上方持續往前，**只在多條軌同時發生事情的時間點降下來**。
匯流點 = 一幕。五個匯流點（依 `timeline.yml` 真實資料算出）：

| # | 時間 | 匯流的軌 | 事件 |
|---|---|---|---|
| 1 | 2022-09 → 2023-10 | E + D + C + B | 入學 · ERP 中心 · 網管 · 共創 UDC · 金匠獎 · 研究助理起算 |
| 2 | 2024-03 → 2024-07 | B + A + C + E | PhishForge 畢專 · 團隊成形任 CTO · 發票醫生開工 · 三獎 · 院長獎 |
| 3 | 2024-10 → 2024-12 | C×4 + B + D | GenAI Stars · 資服雙獎 · 數創金獎 · 智慧城市 · LAK 2025 · 帶 30 人卸任 |
| 4 | **2025 全年** | **五軌全亮** | 台積電第一 · 國科會兩案結案 · PrinterChain → pivot → 公司登記 → 淘換算 → U-Start → 臺東最佳創新創業大獎 → oSave 後端 · 工研院兩段 · 書卷 + 系優秀 |
| 5 | 2026-04 → 2026-09 | A×2 + C + E | oSave 行動版 · 醫數 MedaLink · 雙北第三 · 畢業 → 碩士入學 |

第 4 幕是全片唯一一次五條軌同時亮，是高潮。第 5 幕的四條線全部沒有收束 ——
結尾不是終點，是四個向前延伸的箭頭。

鏡頭語法：**直線往前 + 每幕橫移**。不旋轉、不翻滾、不環繞。
roll 上限 3°，只由滾動速度驅動；fov 42° 基準，速度加最多 3.5°。

## 6. 構圖：每幕換邊

| 幕 | 文字 | 3D |
|---|---|---|
| 1 | 左 | 右 |
| 2 | 右 | 左 |
| 3 | 左 | 右 |
| 4 | 右 | 左 |
| 5 | 置中 | 環繞 |

換邊轉場：**鏡頭橫移帶動文字**。舊文字往左滑出、新文字從右滑入，
與鏡頭 x 軸位移同一條曲線。一個動作，有因果。
可讀性遮罩必須跟著翻面——文字在右時，漸層方向反過來。

## 7. 作品呈現：粒子重組成截圖

WORK 相關的匯流點上，流場裡的粒子飛到定點、拼成作品截圖的點陣、停一下、再拂散繼續流。
**媒材完全統一：全站只有粒子這一種東西。** 沒有貼圖平面、沒有邊框、沒有掃光。

代價已知：點陣截圖不會很銳利。所以要的是辨識度高、對比強的原圖，不是細節圖。

四件作品，各佔一個層次，不重疊：

| # | 作品 | 是什麼層次 | 點陣來源 |
|---|---|---|---|
| 01 | 財伴 oSave | 產品 | `/images/osave-1.webp` — 三支手機 + 大字，對比最強 |
| 02 | PhishForge | 研究 → 全國第一 | `/images/phishforge-1.png` — 發光標題卡 |
| 03 | 斐闊 Finctory | 組織與架構 | **無截圖**。粒子直接拼成「斐闊」兩字 —— 這件案例本來就不是一個畫面，是一個組織 |
| 04 | 醫數 MedaLink | 一人從對話引擎做到雲端部署 | `/images/medalink-1.jpg` — 行事曆，網格 + 彩點列，點陣拼得出來 |

oSave 的 pivot 是這條線上的事件，不是另一件作品：發票醫生的三張圖留在
`osave.yml` 的 `formerScreenshots`，供案例頁講 pivot 用，不進 3D。

**擺放規則：順序照日期，位置不照日期。** 四張截圖各釘在第 2–5 幕的停留區裡，
一幕一張。理由是鏡頭只在停留時停在中軸的某一側，構圖才有固定答案；
擺在換邊的travel 段，不管偏哪一邊都會壓到文案。所有有日期的主張都在節點與
節點標籤上，截圖是一張圖，不是一個時間戳。

## 8. 後製：訊號語彙，不是底片語彙

| 效果 | 決定 |
|---|---|
| bloom | 保留。threshold 0.92，只挑作者寫進 HDR 的熱點 |
| 顆粒 | 改成極微量掃描線（scanline），不是底片顆粒 |
| 暗角 | 改成邊緣色差（chromatic aberration），極輕 |
| glitch | 不做。轉場斷訊會被讀成沒修好的 bug |

理由：你在看的是一個畫面輸出，不是一卷底片。

| 元件 | 決定 |
|---|---|
| 上方導覽 | 改成 HUD 狀態列。等寬小字：目前幕 / 年份 / 進度 %。數字隨滾動跑 |
| 主題切換 | 留在 HUD 右端，日月圖示。切換要同步重打 3D 的光 |

## 10. 不做（明列，避免偷加）

- 音效、配樂
- GLB / 任何載入的 3D 模型
- 神光（godrays）、流體游標、鏡頭光暈
- Theatre.js 或任何外部動畫編輯器
- 節點 hover 互動（會打斷一鏡到底的節奏）
- 手機版的 3D（< 1024px 與 prefers-reduced-motion 一律走純 DOM 版）

## 11. 品質底線

| 項目 | 標準 |
|---|---|
| 幀率 | 桌機 60fps，中階筆電不低於 45fps |
| 進入條件 | 有 WebGL + 寬度 ≥ 1024 + 未要求減少動態，三者皆真才啟動 |
| 主 bundle | 不含 three。three 走獨立 chunk 且不 prefetch |
| 可搜尋性 | 五幕文字全部在 prerender 的 HTML 裡，不靠 JS 才長出來 |
| 可 seek | 任何滾動位置（滾輪、鍵盤、深連結、往回滾）產生完全相同的一幀 |

## 12. 怎麼驗

```
npx nuxt dev --port 3000
node scripts/check-film.mjs
```

走過整個滾動範圍，斷言這些在開發過程中**默默壞掉過**的事：某一幕渲染但畫面上沒有文字、
文案溢出到固定頁首底下、粒子截圖組裝在文字上面、片長在版面穩定前就被量掉、
手機或 prefers-reduced-motion 下 WebGL 仍然啟動。同時把每一幕的畫面存到暫存資料夾——
這裡大部分真正的問題是用看的才發現的，不是斷言抓到的。

⚠️ dev 與 generate 本來共用 `.nuxt`，所以 dev server 開著的時候跑 generate，正式建置的
server bundle 會蓋掉它，之後每一個 request 都 500（`#internal/nuxt/paths is not
defined`），而且 dev server 自己不會發現也不會復原。現在 `npm run generate` 走
`scripts/generate.mjs`，設 `NUXT_BUILD_DIR=.nuxt-generate`，兩邊不再碰同一批檔案，
dev 開著也能安全 generate。（env var 寫在包裝腳本裡而不是 npm script，因為
`VAR=value cmd` 在 cmd.exe 與 PowerShell 都不是合法語法。）

`npm run dev` 的 `predev` 還留著 `scripts/clean-stale-builddir.mjs` 當保險，處理修好
之前留下的舊狀態，或有人直接下 `npx nuxt generate` 的情況。它是看 bundle 裡有沒有那個
解不開的 import，不是看檔案在不在——dev 也會寫同一個檔名。

⚠️ 兩個指令都要走 npm script。`npx nuxt generate` 會跳過包裝腳本，直接寫進 `.nuxt`。
